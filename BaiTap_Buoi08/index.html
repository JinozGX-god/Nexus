"Hello JS Console" - Đối Thoại Với Trình Duyệt

Mở tab Console (F12) để khai báo tên, tuổi và thực hiện các phép toán cộng trừ nhân chia trực tiếp. Sử dụng tư duy Vibe Coding để hiểu sâu cơ chế ép kiểu String trong JavaScript.

Mã Nguồn Khai Báo & Toán Tử Cơ Bản

// 1. Khai báo họ tên và tuổi sinh viên LHU
const tenSinhVien = "Mạc Thùy Thiên Ân";
const tuoiSinhVien = 20;

// 2. Thực hiện các phép toán số học trực tiếp
const a = 15, b = 4;
console.log("Cộng:", a + b);      // 19
console.log("Trừ:", a - b);       // 11
console.log("Nhân:", a * b);      // 60
console.log("Chia:", a / b);      // 3.75
console.log("Chia dư:", a % b);   // 3

Vibe Coding · Trợ Lý AI Phân Tích

"Tại sao khi cộng '10' + 20 trong JS lại ra '1020' mà không phải 30?"

1. Cơ chế Ép kiểu ngầm định (Type Coercion): Toán tử + trong JavaScript đảm nhận 2 nhiệm vụ: Phép cộng số học (Addition) và Phép ghép chuỗi (String Concatenation).
2. Quy tắc ưu tiên nối chuỗi của ECMAScript: Nếu có ít nhất 1 toán hạng là String (ở đây là '10'), JS sẽ tự động chuyển đổi toán hạng còn lại (số 20) thành chuỗi '20' rồi thực hiện nối hai chuỗi:
'10' + '20' = '1020'.
3. Sự khác biệt với các toán tử khác: Các toán tử -, *, / chỉ dành riêng cho số học. Do đó, '10' - 20 sẽ ép '10' thành số 10 và trả về -10!
4. Giải pháp để ra kết quả 30: Ép kiểu tường minh trước khi tính toán:
• Number('10') + 20 = 30
• parseInt('10', 10) + 20 = 30
• +'10' + 20 = 30 (Toán tử Unary Plus)

"Logic Builder" - Máy Tính Mini & Xếp Loại Điểm Số

Học phần 111101 Thiết kế Web · Giáo trình giảng dạy Lạc Hồng Trang 60. Sử dụng cấu trúc điều kiện if - else if - else để kiểm tra điều kiện đạt/hỏng và phân loại học lực: Giỏi (>8), Khá (>6.5), Trung bình (>=5), Yếu (<5).

Thử Nghiệm Tương Tác Trực Quan (Real-time)

Kéo thanh trượt hoặc gõ trực tiếp điểm số từ 0.0 đến 10.0 để quan sát thuật toán phân loại logic cập nhật tức thời:

Giỏi (Grade A)

Chúc mừng bạn đã đạt loại Giỏi! Thành tích xuất sắc!

8.5 Điểm số
Bảng Tiêu Chí Giáo Trình Lạc Hồng:
• Điểm > 8.0: Loại Giỏi • Điểm > 6.5: Loại Khá • Điểm >= 5.0: Trung Bình (Đạt) • Điểm < 5.0: Yếu (Chưa đạt)

Thực Thi Bằng prompt() & alert()

Đây là phương thức tương tác nguyên bản theo đúng yêu cầu đề thi & giáo trình:

  • Sử dụng hộp thoại prompt() để người dùng nhập điểm số trực tiếp từ bàn phím.
  • Sử dụng hàm parseFloat() để ép chuỗi nhập sang số thực.
  • Kiểm tra cấu trúc if (score >= 5) để thông báo "Chúc mừng bạn đã đạt!" hoặc "Rất tiếc, hãy cố gắng hơn!".
  • Hiển thị toàn diện kết quả bằng hộp thoại alert() và in vào console.log().
const input = prompt("Nhập số điểm của bạn:");
const score = parseFloat(input);
if (score >= 5) {
  alert("Chúc mừng bạn đã đạt!");
} else {
  alert("Rất tiếc, hãy cố gắng hơn!");
}

"AI Logic Explainer" - Dịch Mã JS Sang Ngôn Ngữ Tự Nhiên

Phân tích các đoạn mã lỗi, hiện tượng kỳ lạ và bẫy cú pháp kinh điển trong JavaScript. Sinh viên sử dụng AI để "dịch" mã sang luồng tư duy tự nhiên để làm chủ Call Stack và Execution Context.

Đoạn Mã Gốc Cần Phân Tích:

console.log(x); // In ra gì?
var x = 10;

console.log(y); // In ra gì?
let y = 20;

AI "Dịch" Sang Ngôn Ngữ Tự Nhiên:

Bước 1: Khởi tạo biến var x (Hoisting) JS di chuyển việc khai báo var x lên đầu phạm vi và tự động gán giá trị khởi tạo là undefined. Do đó, dòng log đầu tiên in ra undefined chứ không bị lỗi.
Bước 2: Temporal Dead Zone (TDZ) với let y Biến let y cũng được hoisted nhưng không được khởi tạo giá trị. Khu vực từ đầu phạm vi đến dòng khai báo gọi là "Vùng chết tạm thời" (TDZ). Truy cập vào sẽ vấp lỗi ngay: ReferenceError: Cannot access 'y' before initialization.
Bài học rút ra: Luôn sử dụng const hoặc let và khai báo biến ở đầu khối lệnh để tránh các hành vi khó đoán của var.

Đoạn Mã Gốc Cần Phân Tích:

console.log([] == ![]); // Kết quả là true hay false?

AI "Dịch" Từng Bước Thực Thi:

Bước 1: Toán tử phủ định ! có độ ưu tiên cao hơn [] là đối tượng dạng mảng (truthy), do đó phủ định ![] chuyển thành giá trị Boolean false.
Bước 2: So sánh lỏng lẻo [] == false Quy chuẩn so sánh ép kiểu Boolean sang Number: false → 0. Ta được biểu thức [] == 0.
Bước 3: Mảng ép sang nguyên thủy [] gọi valueOf() rồi toString() thành chuỗi rỗng "". Chuỗi rỗng ép sang số thành 0. Cuối cùng: 0 == 0 → true!

Đoạn Mã Gốc Cần Phân Tích:

console.log(0.1 + 0.2 === 0.3); // false! Tại sao?

AI "Dịch" Sang Ngôn Ngữ Tự Nhiên:

Chuẩn dấu phẩy động IEEE 754: Máy tính lưu trữ số dưới dạng nhị phân (Binary). Các phân số thập phân như 0.1 và 0.2 khi đổi sang nhị phân sẽ thành số vô hạn tuần hoàn.
Kết quả thực tế trong bộ nhớ: 0.1 + 0.2 = 0.30000000000000004. Do đó, so sánh nghiêm ngặt === 0.3 trả về false.
Cách khắc phục chuẩn trong lập trình tài chính/web: Sử dụng sai số cho phép: Math.abs((0.1 + 0.2) - 0.3) < Number.EPSILON hoặc làm tròn với Number((0.1 + 0.2).toFixed(2)).

Đoạn Mã Gốc Cần Phân Tích:

for (var i = 1; i <= 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// Kết quả in ra: 4, 4, 4 thay vì 1, 2, 3!

AI "Dịch" Sang Ngôn Ngữ Tự Nhiên:

Cơ chế Event Loop & Phạm vi biến: Từ khóa var không có block scope (chỉ có function/global scope). Cả 3 lần lặp đều tham chiếu tới duy nhất 1 ô nhớ biến i.
Hàm bất đồng bộ setTimeout: Vòng for chạy kết thúc ngay lập tức, làm biến i tăng lên đến 4. Sau đó 100ms, hàng đợi tác vụ (Callback Queue) mới thực thi các hàm callback và in ra giá trị hiện tại của i là 4.
Cách sửa hiện đại: Chỉ cần thay var i bằng let i. Vì let có Block Scope, mỗi vòng lặp sẽ đóng gói một giá trị i độc lập!

Hệ Thống 6 Bài Tập Tự Rèn Luyện (Homework)

Mỗi bài tập được thiết kế đầy đủ hai chế độ: Hộp thoại nguyên bản theo đề bài (prompt() / alert() / console.log()) và Giao diện tính toán tương tác trực quan với định dạng dữ liệu chuẩn Việt Nam.

01

Chuyển Đổi Tiền Tệ Đơn Giản

Nhập số lượng USD và tính ra số tiền VND tương ứng (giả sử tỉ giá 25.000). Kết quả in ra console.

2.500.000 ₫ (Tỉ giá 25.000 ₫/USD)
USD * 25.000
02

Kiểm Tra Số Chẵn / Lẻ

Nhập một số bất kỳ từ bàn phím. Thông báo cho người dùng biết đó là số chẵn hay số lẻ.

42 là số CHẴN.
n % 2 === 0
03

Tính Chỉ Số BMI Cơ Bản

Nhập chiều cao (m) và cân nặng (kg). Tính BMI = cân nặng / (chiều cao * chiều cao) và in ra kết quả.

BMI: 20.55 - Bình thường (Normal weight)
W / (H * H)
04

Logic Đăng Nhập (Mô Phỏng)

Tạo 2 biến username và password cố định. Nếu đúng cả 2 thì hiện "Đăng nhập thành công", nếu sai 1 trong 2 thì hiện "Thông tin không chính xác".

Đăng nhập thành công
u === U && p === P
05

Máy Tính Giảm Giá (Discount)

Nhập hóa đơn. Nếu số tiền > 500.000đ thì giảm giá 10%, ngược lại không giảm. Tính số tiền cuối cùng phải trả.

Phải trả: 675.000 ₫ (Đã giảm 10%: 75.000 ₫)
> 500k ? -10% : 0%
06

Phân Loại Tam Giác

Nhập 3 cạnh của tam giác. Kiểm tra xem đó có phải là tam giác đều không (3 cạnh bằng nhau) & vẽ hình minh họa.

Tam giác ĐỀU: Cả 3 cạnh bằng nhau (a = b = c = 5).
a === b && b === c
