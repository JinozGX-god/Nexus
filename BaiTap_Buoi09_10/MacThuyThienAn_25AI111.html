Sử dụng vòng lặp for để in ra dãy số từ 1 đến 100 trên Console. Sau đó tùy chỉnh để chỉ in ra các số chẵn (i % 2 === 0).

3 Thành Phần Bên Trong Ngoặc Đơn của Vòng Lặp for:

for (let i = 1; i <= 100; i++) {
  // Khối lệnh thực thi
}
1. Khởi tạo (Initialization - let i = 1): Chạy duy nhất một lần khi vòng lặp bắt đầu để khai báo và khởi tạo biến đếm.
2. Điều kiện (Condition - i <= 100): Kiểm tra trước mỗi lần lặp. Nếu true thì thực thi khối lệnh; nếu false thì dừng vòng lặp ngay.
3. Bước nhảy (Update - i++): Chạy sau mỗi lần lặp hoàn tất để tăng/giảm biến đếm trước khi kiểm tra lại điều kiện tiếp theo.

"Function Factory" - Nhà Máy Xử Lý Dữ Liệu

Giáo trình Lạc Hồng Trang 65: Viết hàm tinhDienTich(dai, rong) gọi 3 lần với tham số khác nhau và xây dựng hàm trả về lời chào kết hợp tính tuổi dựa trên năm sinh.

1. Hàm tinhDienTich(dai, rong)

function tinhDienTich(dai, rong) {
  return dai * rong;
}
// Gọi hàm 3 lần với các thông số khác nhau
tinhDienTich(5, 3);    // 15
tinhDienTich(12, 7);   // 84
tinhDienTich(20, 15);  // 300
Lần 1 (5×3) = 15 | Lần 2 (12×7) = 84 | Lần 3 (20×15) = 300

"Refactoring Challenge" - Đóng Gói Hàm Tính Thuế

Đóng gói đoạn code tính thuế thu nhập cá nhân lặp lại thành một hàm tinhThueThuNhap(luong) có thể tái sử dụng cho nhiều mức lương khác nhau.

Đoạn Mã Đã Được Tối Ưu Hóa (Refactored Function)

function tinhThueThuNhap(luong) {
  if (luong <= 11000000) return 0;
  if (luong <= 20000000) {
    return (luong - 11000000) * 0.1;
  }
  return (900000) + (luong - 20000000) * 0.2;
}

Thử Nghiệm Hàm Tính Thuế Với Mức Lương Bất Kỳ

Thuế TNCN: 700.000 ₫ | Thực lĩnh: 17.300.000 ₫

"The Element Picker" - Truy Tìm Thẻ Trên Cây DOM

Minh Họa Truy Tìm Thẻ
