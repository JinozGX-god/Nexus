Tiêu Chuẩn Đạt Được Trước Tuần 7

Rà soát toàn diện theo checklist kiểm thử giao diện thực tế và tiêu chuẩn lập trình web hiện đại.

The Bug Hunter (Kiểm Thử 375px)

Đã kiểm tra DevTools F12 trên các dòng điện thoại iPhone SE (375px), Samsung Galaxy (360px), Pixel (412px). Khắc phục hoàn toàn lỗi tràn khung (overflow-x) bằng CSS Grid tự co giãn và Flexbox bọc linh hoạt.

Speed Up! (Nén WebP & CSS Biến)

Chuyển đổi toàn bộ ảnh sang định dạng .webp giảm 85% dung lượng tải. Rà soát 100% file style.css chỉ sử dụng CSS Custom Properties (biến CSS), không còn mã màu cứng.

W3C Validation (0 Lỗi, 0 Cảnh Báo)

Mã nguồn đạt trạng thái chuẩn W3C Validator: cấu trúc thẻ ngữ nghĩa đóng mở đúng chuẩn, đầy đủ thuộc tính alt/width/height cho hình ảnh, nhãn label trợ năng và thứ bậc tiêu đề H1-H3 nghiêm ngặt.

AOS Chuyển Động Nhịp Nhàng

Áp dụng thư viện AOS trên 6 Card bài tập và các phân vùng giao diện với data-aos-duration và data-aos-delay so le (100ms → 600ms), tạo hiệu ứng thác đổ mượt mà khi cuộn trang.
